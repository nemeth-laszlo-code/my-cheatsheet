# CheatSheet

Developer reference-cheatsheet application in Nuxt 4 + Nuxt Content.

## Clone

```bash
git clone <REPO_URL>
cd my-cheatsheet
```

## Install dependencies

```bash
npm install
```

## Development server

```bash
npm run dev
```

Start development server: `http://localhost:3000`

## Build

```bash
npm run build
npm run preview
```

## Documentation

- Documentation available in the DOCUMENTATION.md
  
## Scripts

- `npm run dev` → development server
- `npm run build` → production build
- `npm run preview` → preview build
