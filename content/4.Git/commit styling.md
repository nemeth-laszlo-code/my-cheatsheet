description: Git Commit Styling

| Type     | Mikor használd                            |
| -------- | ----------------------------------------- |
| feat     | Új funkció                                |
| fix      | Hibajavítás                               |
| chore    | Egyéb karbantartás (pl. deps, config)     |
| docs     | Dokumentáció                              |
| style    | Csak kód formázás, eslint, jelölések      |
| refactor | Kód refaktorálás, nem új feature vagy fix |
| test     | Tesztek hozzáadása / javítása             |
| perf     | Teljesítmény javítás                      |



## Példák:
- feat(shared): add signals-based ingredient selector
- fix(toast): prevent ESLint no-useless-statement warnings
- chore: update eslint and husky setup
- docs(recipe): add usage notes for new component
- style: format select component according to prettier
- refactor(shared): simplify selected.set logic
