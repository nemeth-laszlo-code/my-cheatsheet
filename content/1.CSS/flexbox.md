# Flexbox CheatSheet

A Flexbox segítségével könnyen elrendezheted az elemeket egy dimenzióban.

## Gyakori beállítások

### Középre igazítás
Ha mindent középre akarsz tenni a szülő elemen belül:

```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}
