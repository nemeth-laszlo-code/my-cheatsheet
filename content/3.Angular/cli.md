# Angular CLI telepítése ls használata

```bash
npm i -g @angular/cli
```

## Projekt létrehozása
```bash
ng init 
```

## Dev server elinditása
```bash
ng serve 
```
## Komponens létrehozása, akár relatív elérési útvonallal
```bash
ng g c komponens_neve 
ng g c components/komponens_neve
```
## Osztály létrehozása
```bash
ng g class osztaly_neve
```

## Service létrehozása
```bash
ng g s service_neve
```

## Pipe létrehozása
```bash
ng g p pipe_neve
```
## Validátor létrehozása
```bash
ng g validator validator_neve

```
